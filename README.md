# Lexi's NYC Adventure ✨

A beautiful, Stripe-inspired itinerary application for exploring New York City.

## Design Philosophy

This project embraces Stripe's signature design aesthetic:

- **Clean Typography**: Inter font family for optimal readability
- **Generous Spacing**: Ample white space for a breathable, elegant layout
- **Subtle Animations**: Smooth transitions and micro-interactions
- **Card-Based Design**: Elevated cards with soft shadows
- **Gradient Accents**: Beautiful gradient backgrounds and hover effects
- **Modern Color Palette**: Professional blues, purples, and neutral tones
- **Responsive Design**: Seamless experience across all devices

## Features

- 📅 **3-Day Itinerary**: Carefully curated NYC experiences
- 🎨 **Beautiful UI**: Stripe-inspired modern design
- ✨ **Smooth Animations**: Elegant transitions and effects
- 📱 **Fully Responsive**: Perfect on mobile, tablet, and desktop
- 🎯 **Interactive**: Tab-based navigation for each day
- 🎭 **Rich Content**: Detailed descriptions, times, and locations

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Visit `http://localhost:5173` to view the app.

### Build

```bash
npm run build
```

## Tech Stack

- **React 18**: Modern React with hooks
- **Vite**: Lightning-fast build tool
- **CSS3**: Custom animations and gradients
- **Inter Font**: Professional typography
